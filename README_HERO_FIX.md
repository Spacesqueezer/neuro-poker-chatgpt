# HERO detection fix v2

Исправлена проблема после HandStateTracker v1.

Причина:
- board работает стабильно;
- HERO иногда отдаёт 0/1 карту из-за перекрытия UI;
- старый tracker требовал ровно 2 карты и не создавал новое состояние.

Изменение:
- HERO обновляется мягко;
- пустой кадр больше не стирает найденные карты;
- одна найденная карта обновляет только свой slot;
- board logic не менялась.

# Poker Vision Samples v1

Стартовый датасет PokerDom.

Содержимое:
- anchor — элементы для поиска окна;
- tables — область стола;
- cards — карты героя;
- players — игроки и ники;
- actions — кнопки действий.

Предполагаемый следующий этап:
онлайн-сбор неизвестных элементов в отдельную папку для последующей разметки.

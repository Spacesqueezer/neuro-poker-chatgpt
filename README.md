# Neuro Poker

Исследовательская среда для Texas Hold'em: симуляция раздач, агенты, статистика соперников, обучение нейросети, ограниченный CFR/MCCFR solver и распознавание стола PokerDom.

## Быстрый старт

Требуется Python 3.12 или новее. Команды выполняются из корня проекта в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev,ml,vision]"
python -m pytest -q
```

Если окружение уже настроено, достаточно активировать его. После переноса проекта или переустановки Windows окружение нужно восстановить; копия старой `.venv` не заменяет установку Python.

Для Vision нужен отдельно установленный Tesseract OCR. Для обучения на GPU нужна подходящая сборка PyTorch; проверка описана в [руководстве по обучению](docs/LEARNING.md).

## Что уже есть

- Движок ставок, all-in, побочных банков и showdown; воспроизводимая история раздач.
- Публичный API для агентов и Arena, базовые стили игры и эвристический ExpertAgent.
- Статистика игроков, память соперников, SQLAlchemy и миграции Alembic.
- PyTorch-модель, имитационное обучение, self-play и policy gradient.
- Отдельный ограниченный heads-up solver и экспорт обучающих записей.
- Распознавание карт, имён и элементов стола, отладочный просмотр и HUD.

Наличие этих модулей не доказывает силу стратегии. Solver решает ограниченную игру; интеграция нейросетевого советника с полным состоянием экрана ещё требует доработки.

## Данные проекта

`src/poker/` — библиотека, `tools/` — инструменты, `tests/` — тесты, `migrations/` — миграции.
`assets/` содержит шаблоны распознавания, `captures/` — сохранённые кадры,
`datasets/` — обучающие данные, `models/` — веса,
`artifacts/` — истории и отчёты. `ready_agents/` и `tournament_winner/` содержат результаты отбора моделей.

Шаблоны изображений в `assets/` доступны для добавления в Git. Локальные кадры,
веса и результаты обучения исключены через `.gitignore`. Настройки
`vision_config.json` уже отслеживаются Git; их образец — `vision_config.json.example`.

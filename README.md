# Three anchor calibration v2

Использовать три независимых якоря:

- top_left — зелёный значок PokerDom слева сверху
- top_right — кнопка подарка справа сверху
- bottom_left — иконка чата снизу слева

После загрузки этих шаблонов размер области стола должен считаться по пересечению якорей, а не фиксированным ROI.

Если клиент меняет размер окна:
1. Поискать все три якоря.
2. Рассчитать новый прямоугольник стола.
3. Только потом запускать распознавание карт, игроков и кнопок.

Красные отметки не нужны — шаблоны вырезаны напрямую из чистого скрина.

# Poker Vision

## Назначение

Модуль компьютерного зрения для подключения PokerDom к Poker AI Engine.

Задача:
- найти покерный стол;
- определить позицию Hero;
- получить карты;
- получить состояние игры;
- передать JSON в ядро нейросети.

---

# Структура

assets/

anchor/
- образцы для поиска окна PokerDom

cards/
- образцы карт

players/
- образцы игроков и ников

actions/
- кнопки действий

unknown/
- автоматически найденные неизвестные элементы


---

# Запуск

Из корня проекта:

python src/poker/vision/runner.py


---

# Настройка

Файл:

vision_config.json

Параметры:

hero_name
- ник героя
- пример:
spacesqueezer


capture.monitor
- номер монитора


anchor.threshold
- минимальная уверенность поиска


---

# Как работает обучение

Система не переобучает нейросеть на лету.

Она собирает неизвестные элементы:

unknown/
    cards/
    text/
    buttons/


Пример:

Карточка распознана с низкой уверенностью:

rank=A
suit=?

Изображение сохраняется.

После проверки человеком образец переносится:

unknown -> cards


---

# Добавление новых образцов

1. Сделать скриншот.
2. Вырезать стабильный элемент.
3. Добавить PNG в соответствующую папку.

Например:

assets/anchor/new_anchor.png

# Отладка

Рекомендуемый порядок:

1. Проверить поиск окна.
2. Проверить определение стола.
3. Проверить Hero по нику.
4. Проверить карты.
5. Проверить кнопки.

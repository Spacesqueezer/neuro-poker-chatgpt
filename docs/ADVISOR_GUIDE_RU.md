# Руководство по Режиму Советника (Advisor Mode)

Это руководство описывает работу с модулем компьютерного зрения (Vision) в проекте Neuro Poker и использование бота в качестве **Советника (Advisor Mode)**.

## ⚠️ Важное предупреждение о безопасности (Anti-Ban)
В проекте **полностью удалена** логика автоматического управления мышью и клавиатурой (`ActionExecutor` из модуля `automation`).
Покер-румы (PokerStars, GGPoker и др.) используют продвинутые античит-системы, которые легко обнаруживают программные клики мышью (отсутствие микро-дрожания курсора, нечеловеческая скорость). Использование кликеров приводит к мгновенным и перманентным банам с конфискацией средств.

Поэтому бот работает исключительно в **Режиме Советника**:
1. Бот делает скриншоты вашего экрана (только чтение).
2. Анализирует карты, размер банка и позиции.
3. Нейросеть вычисляет математически оптимальное действие.
4. **Бот выводит текстовую подсказку в консоль** (или поверх экрана в будущем).
5. **Вы сами** принимаете решение и кликаете мышью в клиенте покер-рума.

---

## Текущий статус разработки (Фаза 8)

На данный момент (Фаза 8) модуль компьютерного зрения (`src/poker/vision`) находится на стадии интеграции с движком.
Инфраструктура перевода визуальных данных в тензоры нейросети (`ScreenTranslator`) готова и протестирована.

Однако, **реальное распознавание пикселей (OCR, Template Matching) пока заменено заглушкой**.
Чтобы реализовать точный парсинг реального стола, разработчику требуются эталонные скриншоты из вашего конкретного покер-рума для настройки шаблонов мастей, номиналов карт и шрифтов стеков.

В скрипте `tools/run_advisor.py` используется функция `get_dummy_screen_state()`, которая симулирует то, что бот "видит" на префлопе карманных Тузов.

## Как запустить Режим Советника

Для запуска Советника вам потребуется натренированная модель нейросети (файл `.pt`), которую вы получили по итогам обучения (см. `NEURO_USAGE.md`).

Выполните команду из корня проекта:

```bash
python tools/run_advisor.py --model ready_agents/best_model_placeholder.pt
```

*(Замените `best_model_placeholder.pt` на имя вашего реального файла).*

### Как выглядит вывод Советника

Советник работает в бесконечном цикле (прерывается по `Ctrl+C`). Когда бот обнаруживает по скриншоту, что наступил "Ваш ход", он вычисляет действие и печатает его в консоль:

```text
[Vision] Обнаружен наш ход! Парсим стол...
==================================================
РАЗДАЧА: Стрит=preflop, Банк=1.5, Карты=['A♠', 'A♥']
ДОСТУПНЫЕ ДЕЙСТВИЯ: ['FOLD', 'CALL', 'RAISE', 'ALL_IN']
РЕКОМЕНДАЦИЯ НЕЙРОСЕТИ: *** RAISE 3.0 ***
==================================================
```

Вам остается только посмотреть на рекомендацию (`RAISE 3.0`), переключиться в окно покер-рума и вручную сделать этот рейз.

## Дальнейшие шаги по интеграции реального зрения

Как только будут получены скриншоты вашего рума:
1. В `src/poker/vision` будут добавлены функции OpenCV для нарезки скриншота на зоны (bounding boxes).
2. Функция `get_dummy_screen_state()` в `tools/run_advisor.py` будет заменена на вызов реального пайплайна (например, `mss` для быстрого захвата экрана + `pytesseract` / `cv2.matchTemplate` для распознавания).
3. (Опционально) Текстовый вывод в консоль может быть заменен на полупрозрачный HUD (Overlay), рисующий подсказки прямо поверх окон Windows с помощью `PyQt` или `Tkinter`.

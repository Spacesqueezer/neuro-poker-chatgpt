# Neuro Poker Project Context

## Overview

Neuro Poker is a project to build an autonomous Texas Hold'em AI system.

The final system should be able to:
- understand poker table state through computer vision;
- convert visual information into structured game state;
- evaluate mathematical aspects of poker;
- model opponents;
- make strategic decisions;
- execute actions through an external interface.

The project starts from a clean architecture. Previous poker implementation is not reused.

## Core Principles

- AI-assisted development through NeuroPatch.
- Every feature has tests.
- Architecture before optimization.
- Deterministic and reproducible experiments.
- Clear separation between systems.

## Final Goal

Create a poker intelligence system capable of:
- cash game play from heads-up to 10 players;
- opponent analysis;
- risk evaluation;
- bluffing;
- hand strength evaluation;
- strategic adaptation.

## Major Systems

1. Poker Engine
2. Simulation Environment
3. Mathematical Analysis Layer
4. Agent System
5. Training System
6. Opponent Database
7. Computer Vision Layer
8. Action Execution Layer
